关于播放、书签、备份与资料来源的常见问题。本页介绍新版预览中的播放、阅读与本机记录功能。新版正在准备更新。

开始一次听读

  1. 在“发现”选择人物、博弈或制度，或从专题档案进入关联内容。
  2. 有声长篇可播放完整本地样音，也可打开同一集的全文。短读明确标为“只读”。
  3. 播放时添加书签和备注，在“我的书房”查看历史、书签与收藏。
  4. 需要换机或卸载前，从“备份”导出 JSON 并确认文件保存完成。

常见问题

现在可以下载新版吗？

新版正在准备更新，当前页面用于介绍新版内容与界面，暂不提供新版下载。正式发布后，我们会在这里更新获取方式。

需要联网、账号或订阅吗？

本页展示的新版无账号，播放和阅读使用内置内容，不包含广告 SDK 或分析 SDK。你主动打开外部史料网站、保存文件到云盘或发送支持邮件时，相关系统服务可能需要网络。

为什么听到的是合成声音？

本次预览以系统合成声音朗读原创秦史文稿，方便在听与读之间切换。它不是原版演播，也不包含原作逐字稿。

进度、书签和收藏能自动同步到另一部手机吗？

不能。记录保存在本机，不提供账号云同步。请主动导出 JSON 备份，在另一设备选择导入。导入前会校验并显示预览，较新的同版本章节进度优先，重复书签去重，设置按预览提示恢复。

导入后出现“未关联记录”是什么意思？

记录对应的章节 ID 或内容版本没有安装。应用保留这些记录，但不会仅凭相似标题挂到另一篇内容上。原版数据迁移未经验证，不承诺从旧应用自动恢复。

清除历史会删除所有资料吗？

单条历史删除不会删除书签；设置里的“清除收听记录”会清进度、书签、收藏与统计，保留设置与欢迎状态。操作前请核对提示，并导出需要保留的资料。

怎样核对内容中的史实？

全文末尾和详情页提供来源名称、引用位置及阅读提示，全文阅读可点“来源”定位。原始资料链接在你确认后打开。内容区分古籍记载、现代解释和分析案例；仍有争议的内容不作为确定事实。

发现错字、史实问题或来源失效怎么办？

请记录篇章标题、正文小节、问题句子及建议依据。若是播放问题，可同时记录发生位置、iOS 与应用版本。只需发送必要信息，不必提供完整个人备份。
